# STR-Consulting Homebrew Tap

Shared Homebrew tap for STR-Consulting CLI tools.

## Installation

```bash
brew tap STR-Consulting/tap
brew install cupa
```

## Formulae

| Formula | Description |
|---------|-------------|
| `cupa` | MCP server for ClickUp Agent Notes cross-agent conversation |

## Updating

```bash
brew update
brew upgrade cupa
```
